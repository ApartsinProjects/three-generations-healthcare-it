# Three Generations of Healthcare IT

Position paper: *Three Generations of Healthcare IT: From the Digital Record to the Computable Care Process.*

**Authors:** Alexander Apartsin (Holon Institute of Technology), Yehudit Aperstein (Afeka Academic College of Engineering).

## Thesis

Healthcare IT is organized by the *unit of information it makes computable*, and its enabling technology:

1. **First generation** digitized the **record** (databases).
2. **Second generation** digitized clinical **facts** (clinical NLP + terminologies + interoperability standards).
3. **Third generation** (emerging) digitizes the **care process** (LLMs + neural-symbolic AI), converting clinical communication into structured, executable, auditable records of intended action.

The paper gives explicit criteria for what constitutes a generation, catalogs each along systems / algorithms / use cases, distinguishes the third generation from classical clinical NLP and computer-interpretable guidelines, states the reliability requirements it imposes, grounds the argument in a working instance (follow-up extraction; hybrid neural-symbolic Pair F1 0.997 vs ~0.53 for general-purpose LLMs), and sets out testable predictions.
